About MiniMuse Tools

MiniMuse Tools is an independent fan-made resource for preparing original artwork and finding concise creation guidance.

What we build

We build a local workspace for original character artwork: create from available starter pieces, repair an uploaded image, combine layers and download the parts or complete picture. Quick Edit remains available for small tasks. Our guides explain the workflow and its limits, alongside official outbound game download links.

Unofficial status
