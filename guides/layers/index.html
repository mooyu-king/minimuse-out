VERIFIED TASK GUIDE

How Layers Work in MiniMuse

Layer order controls which hair, clothes, props and scene elements appear in front. Fix the order before repeatedly resizing an asset.

Last reviewed September 17, 2026 · Verify steps in your current app version

Layer checklist

Select the object that is covered, move it one step at a time, and lock finished elements.

  1. Identify the object that should be in front.
  2. Move it forward one layer and inspect the overlap.
  3. Lock completed background or body elements.
  4. Duplicate only after position and order are correct.
  5. Check the result after reopening the scene.

Version differences

Control names and available joint-following behavior may change. Treat the current app interface and official update notes as authoritative.
