How to Import Custom Assets in MiniMuse

Prepare a PNG you created or are licensed to use, then import it through the current custom art flow in the official MiniMuse app.

Last reviewed September 17, 2026 · Verify steps in your current app version

Before you import

Keep the original file, confirm your right to use it and check the transparency in the prep tool.

  1. Export a clean PNG from the asset prep tool.
  2. Open the original MiniMuse app and find its custom artwork import control; labels can vary by version.
  3. Choose the current import option and select the exported file.
  4. Position, scale and place the item in the correct layer.
  5. Save, reopen the project and confirm the result.

Choose the right download

Current PNG exports an individual artwork layer. Compact output trims transparent space when enabled; full-canvas output includes the rendered placement as pixels, not game attachment data. A complete PNG is a flat picture, not an editable character. Extract ZIP files before selecting individual PNGs. Open .mmstudio backups in this website only.

Check the result in your game

Start with one original accessory or background. Inspect transparency and color, position it, save your work and reopen it. Record your game version and device if it fails. Our image workflow has not yet completed a documented original-game compatibility test; no universal file-size or layer limit is claimed here.

If the screen looks different

MiniMuse changes over time. Use the labels visible in your installed version and consult the official update notes; do not install an unofficial APK to match a tutorial.

Create, repair and combine locally

Upload your artwork to clean an edge, select a region or combine it with other pieces. Download a single PNG whenever it is ready, or keep building the complete picture.
